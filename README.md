# Tela de Login — Profissional

![Preview do Login](assets/images/examples/MuriloDev.png)

Descrição curta
----------------

Tela de login clean e responsiva, criada para ser usada como ponto de partida em projetos web. Design moderno, acessível e otimizado para mobile e tablet.

Principais características
-------------------------

- Layout responsivo (mobile → tablet → desktop)
- Inputs com foco acessível e transições suaves
- Botão de mostrar/ocultar senha (olhinho)
- Botões sociais responsivos (stack em mobile, lado a lado em tablets)
- Fundo com efeito sutil e alto contraste para destaque do card
